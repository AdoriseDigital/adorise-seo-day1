Phase 0: Pre-Work (Week 0)

Don't skip this. The #1 reason implementations stall is lack of executive alignment and dedicated capacity.

✅ Checklist: Week 0

  • [ ] Secure Executive Sponsor: C-level who owns the outcome, unblocks decisions, attends monthly reviews
  • [ ] Approve Budget: Platform ($497-2000/mo), implementation time (5-10 hrs/week), training
  • [ ] Identify Core Team: Process Owner (business), Technical Lead (implementation), Champion (adoption)
  • [ ] Inventory Systems: List every tool with admin access: CRM, email, calendar, project mgmt, accounting, support, docs
  • [ ] Baseline Metrics: Current process times, error rates, volumes, costs for target processes
  • [ ] [ ] Schedule Kickoff: 90-min session with sponsor + team. Agenda: goals, scope, timeline, risks.

Kickoff Meeting Agenda (90 min)

  1. Why Now (10 min): Business driver, competitive pressure, cost of inaction
  2. What Success Looks Like (15 min): Specific metrics: "Reduce lead response from 42 hrs to <5 min", "Save 20 hrs/week on proposals"
  3. Scope & Boundaries (15 min): What's in/out. Start with 3 pilots. No "boil the ocean."
  4. Platform Decision (15 min): Compare options. Recommend AI Automation Suite for speed.
  5. Team & Capacity (15 min): Who does what, when. Protect the time.
  6. Risks & Mitigations (10 min): Data quality, change resistance, technical debt, vendor lock-in
  7. Next Steps & Commitments (10 min): Week 1 tasks, owners, due dates.

Phase 1: Assessment & Strategy (Weeks 1-2)

Goal: Prioritized pilot portfolio with clear success criteria

Week 1: Process Discovery

  • Interview 5-10 process owners across departments (30 min each)
  • Complete Process Inventory Template (see Templates section)
  • Score each process on: Volume, Standardization, Data Readiness, Decision Complexity, Exception Rate, Business Impact
  • Calculate Priority Score = (Volume × Impact × AI Suitability) / (Complexity × Effort)
  • Select top 10 processes. Present to sponsor for approval.

Week 2: Pilot Selection & Planning

  • From top 10, pick 3 pilots: 1 Quick Win, 1 Strategic, 1 Learning
  • Define success criteria for each: specific, measurable, time-bound
  • Map current state for each pilot: trigger → steps → decisions → outputs → exceptions
  • Identify data requirements: what data, where it lives, access method, quality
  • Risk assessment per pilot: technical, organizational, compliance
  • Get sponsor sign-off on pilot portfolio.

Pilot Selection Framework

Type Characteristics Example Timeline
Quick Win High volume, rules-based, structured data, low exceptions Invoice data entry, lead enrichment, meeting summaries Week 5-6
Strategic High impact, judgment needed, semi-structured data Lead qualification, proposal generation, customer onboarding Week 7
Learning Complex, cross-functional, unstructured data Order-to-cash, hire-to-retire, incident response Week 8-9

Phase 2: Platform & Foundation (Weeks 3-4)

Goal: Platform configured, all integrations live, team productive

Week 3: Platform Setup

  • Provision platform account (AI Automation Suite recommended)
  • Complete white-glove onboarding (included with AI Automation Suite)
  • Configure authentication: SSO, API keys, OAuth for all target systems
  • Set up environments: Development, Staging, Production
  • Configure secrets management: centralized, rotation schedule
  • Enable observability: logging, metrics, alerting (Slack/email)

Week 4: Integrations & Team Enablement

  • Connect all core systems: CRM, email, calendar, project mgmt, accounting, support, docs
  • Test each integration: trigger → action → verify data flow
  • Build reusable components: shared auth, error handler, naming conventions, variable templates
  • Team training (2 hours): platform basics, building workflows, debugging, best practices
  • Create internal documentation: "How We Automate" guide in Notion/Confluence
  • Establish support channel: Slack #automation-help with 4-hour SLA

Phase 3: Pilot Development (Weeks 5-7)

Goal: 2 workflows live in production, measured, documented

Week 5: Quick Win — Build & Shadow

Example Quick Win: "New Lead → Enrich → Score → Route → Notify"

  1. Build workflow in platform using visual builder
  2. Configure: Trigger (new CRM contact) → Enrich (Apollo) → Score (rules) → Branch (assign/nurture/archive) → Notify (Slack) → Log (CRM)
  3. Deploy in shadow mode: executes but doesn't write to production systems
  4. Run 48 hours. Compare shadow output vs manual process for 20+ test cases
  5. Fix discrepancies. Document edge cases.

Week 6: Quick Win — Go Live & Measure

  1. Ramp traffic: 10% → 50% → 100% over 3 days
  2. Monitor: execution time, success rate, error types, data quality
  3. Measure against baseline: time saved, error reduction, team feedback
  4. Document: workflow spec, test results, runbook, rollback procedure
  5. Retrospective: what worked, what didn't, improvements for next pilot

Week 7: Strategic Pilot — AI Reasoning Workflow

Example Strategic: "Inbound Lead → AI Research → Personalized Outreach → Meeting Booked"

  1. Build with AI nodes: research (Perplexity), generation (Claude), reasoning (scoring)
  2. Implement human-in-the-loop: AI drafts → human approves → sends
  3. Add RAG: upload ICP docs, case studies, battlecards for context
  4. Shadow mode 48 hours → compare AI output quality vs human baseline
  5. Go live with 20% traffic, daily review, ramp to 100% by end of week

Phase 4: Scale & Harden (Weeks 8-10)

Goal: 5-10 workflows live, reusable library, observability complete

Week 8: Learning Pilot + Component Library

  • Deploy Learning Pilot (cross-functional, e.g., "Customer Onboarding End-to-End")
  • Extract reusable components from 3 pilots: CRM connector, Slack notifier, error handler, AI prompt templates
  • Publish component library: versioned, documented, example usage
  • Internal demo day: showcase all 3 pilots to company

Week 9: Observability & Governance

  • Build executive dashboard: workflows live, executions/day, success rate, time saved, ROI
  • Implement alerting: failure rate >5%, latency >SLA, data quality issues
  • Establish change control: request → review → test → deploy → monitor
  • Model governance: test sets for AI nodes, drift detection, retraining schedule
  • Security review: data flow audit, access control, compliance check

Week 10: Champions & Knowledge Transfer

  • Identify 1-2 "Automation Champions" per department
  • Champion training: advanced building, debugging, requesting new workflows
  • Create "Automation Request" process: form → triage (weekly) → prioritize → build
  • Document lessons learned: 10-page "Implementation Playbook"
  • Prepare Month 3 review deck for sponsor

Phase 5: Institutionalize (Weeks 11-12)

Goal: Self-sustaining automation flywheel

Week 11: Intake Pipeline & CoE Charter

  • Formalize intake: Request Form → Weekly Triage → Prioritization Scorecard → Sprint Planning
  • Define CoE (Center of Excellence) charter: mission, funding, roles, roadmap, success metrics
  • Set quarterly budget: platform, development time, training, experimentation fund
  • Create automation catalog: searchable, categorized, with ROI tags

Week 12: Review, Plan, Celebrate

  • Month 3 Review with Sponsor: metrics vs targets, ROI, lessons, next quarter plan
  • Quarterly Roadmap: next 10 workflows, capability gaps, platform evaluation
  • Skill Development Plan: champion certifications, team training, hiring needs
  • Celebrate wins: recognize champions, share success stories company-wide
  • Archive: all docs, code, configs in version control. Handoff complete.

Success Metrics & KPIs

Leading Indicators (Track Weekly)

  • Workflows in Production: Count (target: 3 by W7, 10+ by W12)
  • Daily Executions: Volume trend (target: growing 20% week-over-week)
  • Success Rate: % executions without error (target: >95%)
  • Shadow Match Rate: % new workflows matching manual in shadow (target: >95%)
  • Team Adoption: % champions actively building (target: >80%)
  • Request Pipeline: New automation requests/week (target: >5)

Lagging Indicators (Track Monthly)

  • Total Hours Saved/Month: Sum across all workflows (target: >100 by Month 3)
  • Error Rate Trend: Should decrease as workflows mature
  • Cost Per Execution: Platform cost / executions (target: <$0.10)
  • ROI: (Hours saved × loaded cost) / platform spend (target: >5:1 by Month 6)
  • Process Cycle Time Reduction: % reduction for automated processes (target: >70%)
  • Employee Satisfaction: eNPS for automation (target: >50)

Quarterly Business Review Deck Structure

  1. Executive Summary: ROI, hours saved, workflows live
  2. Portfolio Review: each workflow's metrics, health, roadmap
  3. Capability Assessment: new AI features, platform updates, skill gaps
  4. Pipeline: next quarter's prioritized workflows with expected ROI
  5. Budget: actual vs plan, next quarter request
  6. Risks & Mitigations: technical debt, vendor, compliance, talent
