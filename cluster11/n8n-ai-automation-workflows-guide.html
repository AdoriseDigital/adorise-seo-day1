Structured Output Schema (JSON)

  "type": "object",
  "properties": {
    "score": {"type": "integer", "minimum": 0, "maximum": 100},
    "tier": {"type": "string", "enum": ["hot", "warm", "cool"]},
    "reasoning": {"type": "string"},
    "key_signals": {"type": "array", "items": {"type": "string"}},
    "recommended_action": {"type": "string"}
  },
  "required": ["score", "tier", "reasoning", "key_signals", "recommended_action"]
}

Rate Limiting (Function Node)

// Add delay between items to respect API limits
const delay = (ms) => new Promise(resolve => setTimeout(resolve, ms));

for (const item of items) {
  await delay(100); // 100ms = 10 req/sec max
  // Process item
  const result = await $node['API Call'].execute(item);
  results.push(result);
}
return results;

Self-Hosted n8n: Production Checklist

  • ☐ Docker Compose with queue mode (Redis + 2+ workers)
  • ☐ PostgreSQL (not SQLite) for production
  • ☐ Reverse proxy (Nginx/Traefik) + SSL (Let's Encrypt)
  • ☐ Environment: N8N_ENCRYPTION_KEY, DB credentials, webhook URL
  • ☐ Backup: Daily workflow + credentials export to S3/R2
  • ☐ Monitoring: Health endpoint + Prometheus metrics + Grafana
  • ☐ Log aggregation: Loki or CloudWatch
  • ☐ Updates: Watchtower or manual monthly

Workflow Governance

  1. Naming convention: `category/function/description` (e.g., `sales/lead/qualify-inbound`)
  2. Version control: Export all workflows to Git weekly (n8n CLI or API)
  3. Environment separation: Dev/Staging/Prod instances or workflow tags
  4. Credential rotation: Quarterly rotation documented in runbook
  5. Ownership: Every workflow has a primary + backup owner

FAQ

How do I import these workflows?
In n8n: Workflows → Import → paste JSON. Or use CLI: `n8n import:workflow --input=workflows/`. All 50+ workflows available as JSON in the AI Automation Suite.
Can I run n8n on a $5 VPS?
For <10K executions/mo: yes, with SQLite. For production: $20-40 VPS (2-4 GB RAM) with PostgreSQL + Redis + 2 workers. DigitalOcean/Hetzner/Contabo all work.
What's the learning curve for AI nodes?
If you know n8n basics: 2-3 days to productive with LangChain nodes. Key concepts: prompt engineering, structured output schemas, agent tool design. Community templates accelerate this massively.
How do I debug AI workflow failures?
  • Enable "Continue on Fail" for AI nodes, check output
  • Log raw LLM response (Set node before parser)
  • Test prompts in isolation (playground) before wiring
  • Use structured output — validation errors are explicit
